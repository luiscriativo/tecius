# Política de Privacidade — Tecius

**Última atualização:** 20 de junho de 2026

O Tecius é um aplicativo de desktop, de código aberto, para criação de timelines
visuais pessoais. Esta política descreve como o aplicativo lida com seus dados.

Resumo em uma frase: **o Tecius não coleta, transmite nem vende nenhum dado
pessoal. Todo o seu conteúdo permanece armazenado localmente no seu dispositivo.**

---

## 1. Dados que coletamos

**Nenhum.** O Tecius não coleta dados pessoais, não exige criação de conta, não
faz login e não possui servidores operados pelo desenvolvedor que recebam seus
dados.

Todo o conteúdo que você cria no aplicativo — timelines, eventos, textos, imagens
e demais arquivos do seu *vault* — é gravado **exclusivamente como arquivos
locais no seu próprio computador**. Esses arquivos nunca são enviados para o
desenvolvedor nem para terceiros.

## 2. Telemetria e análise de uso

O Tecius **não possui telemetria, analytics, rastreamento de uso, cookies de
publicidade nem qualquer forma de monitoramento** do seu comportamento.

## 3. Conexões de rede

O aplicativo funciona totalmente offline. As únicas situações em que ele acessa a
internet são:

- **Atualizações automáticas:** o Tecius verifica se há novas versões publicadas
  no GitHub Releases (`github.com/luiscriativo/tecius`). Essa verificação faz uma
  requisição aos servidores do GitHub para baixar informações da versão e, se
  você autorizar, o arquivo de atualização. Como em qualquer acesso à internet, o
  GitHub pode registrar o endereço IP da requisição, conforme a
  [Política de Privacidade do GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  Nenhum dado do seu conteúdo é enviado nessa verificação.
- **Links externos:** ao clicar em links dentro do aplicativo (por exemplo, para
  o repositório, a página de releases ou de problemas no GitHub), o link é aberto
  no seu navegador padrão. A partir daí, aplica-se a política de privacidade do
  site de destino.

## 4. Permissões do sistema

O Tecius acessa o sistema de arquivos do seu dispositivo apenas para ler e gravar
os arquivos do seu *vault*, na pasta que você escolher. Ele não acessa câmera,
microfone, contatos, localização ou outros dados sensíveis durante o uso normal.

## 5. Compartilhamento de dados

Como o Tecius não coleta dados, **não há compartilhamento, venda ou transferência
de dados pessoais** com terceiros.

## 6. Segurança

Seus dados ficam sob seu próprio controle, no seu dispositivo. Recomendamos
manter backups dos arquivos do seu *vault* e proteger seu computador com as
medidas de segurança habituais (senha de usuário, criptografia de disco, etc.).

## 7. Privacidade de crianças

O Tecius não é direcionado a crianças e não coleta intencionalmente dados de
nenhum usuário, incluindo menores de idade.

## 8. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças no aplicativo. A data da
"Última atualização" no topo indica a versão vigente. Alterações relevantes serão
publicadas junto ao repositório do projeto.

# Privacy Policy — Tecius (English)

**Last updated:** June 20, 2026

Tecius is an open-source desktop application for creating personal visual
timelines. One-sentence summary: **Tecius does not collect, transmit, or sell any
personal data. All of your content stays stored locally on your device.**

- **Data collected:** None. No account, no login, no developer-operated servers.
  All content (timelines, events, text, images) is saved only as local files on
  your own computer.
- **Telemetry/analytics:** None. No tracking, advertising cookies, or usage
  monitoring of any kind.
- **Network access:** The app works fully offline. It only reaches the internet
  to (a) check for new versions on GitHub Releases — which may cause GitHub to log
  the request IP per their privacy policy, and sends none of your content — and
  (b) open external links (e.g., the GitHub repository) in your default browser.
- **System permissions:** File-system access is used solely to read/write the
  files of the vault folder you choose. No camera, microphone, contacts, or
  location access during normal use.
- **Data sharing:** Because no data is collected, none is shared, sold, or
  transferred to third parties.
- **Children's privacy:** Tecius is not directed at children and intentionally
  collects no data from any user.
